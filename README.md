# PolySplat Website

Static project page for:

**PolySplat: Workload-Regime-Aware Rasterization for 3D Gaussian Splatting**

## Contents

- `index.html`, `styles.css`, `script.js`: static website files.
- `assets/figures/`: web-ready PNG versions of the paper figures.
- `assets/video/`: the latency-demo MP4 and poster image.

The paper links are currently arXiv placeholders. Replace `href="#top"` in `index.html` with the arXiv URL after upload.

## Local Preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

Push this folder as a repository and enable GitHub Pages from the repository root. No build step is required.
